Available lint rules:

  MPR001 (NamingConvention) - Checks that entities, microflows, pages, and enumerations follow naming conventions
      Category: style, Severity: warning

  MPR002 (EmptyMicroflow) - Checks for microflows, nanoflows and rules that have no activities
      Category: quality, Severity: warning

  MPR003 (DomainModelSize) - Checks that modules have no more than 15 persistent entities
      Category: design, Severity: warning

  MPR004 (EmptyValidationFeedback) - Checks for validation feedback actions with empty message templates (CE0091)
      Category: correctness, Severity: warning

  MPR005 (UnconfiguredImage) - Checks for IMAGE widgets with no source configured (crashes at runtime)
      Category: correctness, Severity: warning

  MPR012 (ReactUnsupportedWidget) - Checks for built-in widgets the React client does not support — static/dynamic image, drop-down, legacy data grid, reference selector (CE0582)
      Category: correctness, Severity: warning

  MPR013 (SnippetCallAppearance) - Checks for snippet calls with Class, Style, DynamicClasses or design properties, which never reach the page (a snippet call renders no element)
      Category: correctness, Severity: warning

  MPR014 (AgentWithoutSelectedModel) - Checks for agents with no selected model, which Agent Editor 2.2+ refuses to import at startup, stopping the import of every agent
      Category: correctness, Severity: warning

  MPR015 (ConsumedMCPServiceWithoutEndpoint) - Checks for consumed MCP services with no endpoint constant, which Agent Editor skips at startup, so they connect nowhere
      Category: correctness, Severity: warning

  MPR006 (EmptyContainer) - Checks for CONTAINER widgets with no children (valid and renders, but usually a leftover)
      Category: quality, Severity: info

  MPR009 (GallerySelectionListener) - Gallery referenced by DataView's `DataSource: selection X` must set ItemSelectionMode: toggle (Studio Pro CE3637)
      Category: correctness, Severity: error

  MPR010 (DataViewLayoutGrid) - A DataView containing input widgets (a form) should be wrapped in a layout grid so label and input widths render correctly
      Category: design, Severity: warning

  QUAL006 (RequiredCaptionMissingDefaultLanguage) - Checks that every caption mxbuild requires (a tab page caption) has text in the project's default language (CE4899)
      Category: quality, Severity: error

  MPR007 (PageNavigationSecurity) - Checks that pages used in navigation have at least one allowed role (CE0557), and that every user role can open its home page (at Production security, else CE2729 per widget)
      Category: security, Severity: warning

  SEC001 (NoEntityAccessRules) - Checks that persistent entities have at least one access rule
      Category: security, Severity: warning

  SEC002 (WeakPasswordPolicy) - Checks that the password policy requires at least 8 characters
      Category: security, Severity: warning

  SEC003 (DemoUsersActive) - Checks that demo users are disabled when security level is Production
      Category: security, Severity: warning

  SEC010 (PageEntityNotReadable) - Checks that the roles allowed on a page may read the entity each of its data widgets lists (at Production security it renders empty for them, silently)
      Category: security, Severity: warning

  SEC011 (XPathAssociationNotReadable) - Checks that a page data source's XPath crosses only associations the roles opening the page may read (at Production the page fails to open: "No access rights for …")
      Category: security, Severity: error

  SEC012 (ReachablePageNotReadable) - Checks that every page a user role can reach shows only attributes and entities the role may read (mxbuild CE2729)
      Category: security, Severity: error

  SEC013 (SecurityLevelIgnoresRules) - Checks that the security level applies the access rules, grants and demo users the project defines
      Category: security, Severity: warning

  MPR008 (OverlappingActivities) - Microflow activities whose canvas positions overlap, typically caused by missing @position annotations in MDL
      Category: correctness, Severity: warning

  MPR011 (LoopChildContainment) - Microflow activities positioned outside the loop container that holds them, which renders wrong in Studio Pro but passes mx check
      Category: correctness, Severity: warning

  CONV011 (NoCommitInLoop) - Commits should not be inside loops, whether a commit action or a create/change with commit (N+1 performance issue)
      Category: performance, Severity: warning

  CONV012 (ExclusiveSplitCaption) - Exclusive splits should have a meaningful caption describing the decision
      Category: quality, Severity: info

  CONV013 (ErrorHandlingOnCalls) - External service calls (REST, web service, Java action) should have custom error handling
      Category: quality, Severity: warning

  CONV014 (NoContinueErrorHandling) - Activities should not use 'Continue' error handling which silently swallows errors
      Category: quality, Severity: warning

  CONV020 (CreatedObjectNeverPersisted) - A microflow creates an object of a persistent entity without committing it, and never commits, returns, passes on, stores or deletes it
      Category: quality, Severity: warning

  CONV021 (CreateChangeThenCommit) - A Create or Change object activity directly followed by a Commit of the same object; set Commit on the create/change instead
      Category: quality, Severity: warning

  MDL-FLOW01 (IrreducibleFlowGraph) - Microflow branch structure cannot be described faithfully as nested if/then/else
      Category: quality, Severity: info

  MDL-MAP04 (ImportRangeOnObjectMapping) - Import activity stores a First range over an object-rooted mapping (throws at runtime)
      Category: correctness, Severity: error

  CONV001 (BooleanNaming) - Boolean attributes should start with Is, Has, Can, Should, Was, or Will
      Category: naming, Severity: info

  CONV002 (NoEntityDefaultValues) - Avoid default values on entity attributes; set them in microflows instead
      Category: quality, Severity: info

  CONV003 (PageNamingSuffix) - Page names should end with a type suffix (_NewEdit, _View, _Overview, _Select, _Details, _Dashboard)
      Category: naming, Severity: info

  CONV004 (EnumerationPrefix) - Enumeration names should start with ENUM_ prefix
      Category: naming, Severity: info

  CONV005 (SnippetPrefix) - Snippet names should start with SNIPPET_ prefix
      Category: naming, Severity: info

  CONV006 (NoCreateDeleteRights) - Entity access rules should not grant CREATE or DELETE directly; use microflows instead
      Category: security, Severity: warning

  CONV007 (XPathOnAllAccess) - Entity READ/WRITE access rules should have XPath constraints for row-level security
      Category: security, Severity: info

  CONV008 (ModuleRoleMapping) - Each module role should be mapped to exactly one user role
      Category: security, Severity: info

  CONV009 (MaxMicroflowObjects) - Microflows should not exceed 15 activities (Mendix best practice)
      Category: quality, Severity: info

  CONV010 (ACTMicroflowContent) - ACT_ microflows should only contain UI actions and sub-microflow calls
      Category: architecture, Severity: warning

  CONV015 (NoEntityValidationRules) - Avoid entity validation rules; use VAL_ microflows for validation instead
      Category: quality, Severity: info

  CONV016 (NoEventHandlers) - Avoid entity event handlers; use explicit microflow calls instead
      Category: performance, Severity: info

  CONV017 (NoCalculatedAttributes) - Avoid calculated attributes; use stored attributes updated by microflows
      Category: performance, Severity: info

  CONV018 (ModuleFolderOrganization) - Modules past a readable size should organise their documents into folders
      Category: quality, Severity: info

  CONV019 (NavigationPageURL) - Pages reachable from navigation should have a URL so they can be linked to directly
      Category: quality, Severity: info

  ARCH001 (Cross-Module Data Access) - Pages and widgets should only use data from entities in the same module
      Category: architecture, Severity: warning

  ARCH002 (Data Changes Through Microflows) - Persistent entities should have microflows that handle data changes (create/update)
      Category: architecture, Severity: warning

  DESIGN001 (Entity Attribute Count) - Entities should not have more than 10 attributes
      Category: design, Severity: warning

  ARCH003 (Entity Business Key) - Persistent entities should have a unique, not-null attribute as a business key
      Category: architecture, Severity: warning

  CUSTOM002 (Microflow Prefix Convention) - Microflows should have standard naming prefixes (ACT_, SUB_, DS_, VAL_, SCH_)
      Category: naming, Severity: info

  CUSTOM001 (Entity PascalCase) - Entity names must use PascalCase naming convention
      Category: naming, Severity: warning

  QUAL003 (Long Microflows) - Microflows should not have more than 25 activities
      Category: quality, Severity: warning

  QUAL001 (McCabe Complexity) - Microflows should not exceed McCabe cyclomatic complexity of 10
      Category: complexity, Severity: warning

  QUAL002 (Missing Documentation) - Model elements should have documentation describing their purpose
      Category: quality, Severity: info

  QUAL004 (Orphaned Elements) - Elements should be referenced somewhere in the project or marked as entry points
      Category: quality, Severity: info

  SEC004 (GuestAccessEnabled) - Guest (anonymous) access is enabled - review all entity access rules for the anonymous user role
      Category: security, Severity: warning

  SEC009 (MissingMemberReadRestriction) - Large entities with entity-level READ access but no attribute-level restrictions
      Category: security, Severity: info

  SEC006 (PiiAttributesWithoutAccessRules) - Entities with PII-sounding attributes should have access rules configured
      Category: security, Severity: warning

  SEC005 (StrictModeDisabled) - Strict security mode is disabled - enables additional XPath constraint enforcement
      Category: security, Severity: warning

  SEC007 (UnconstrainedAnonymousEntityRead) - Entity readable by anonymous users without row-level XPath constraint (DIVD-2022-00019)
      Category: security, Severity: error

  SEC008 (UnconstrainedPiiRead) - Roles can read all rows of entities containing PII without XPath row-scoping
      Category: security, Severity: warning
